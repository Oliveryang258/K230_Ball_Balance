# LaTeX 模板来源与本项目改动

母版来源：

- SandOcean-ovo, `Template-for-Electrical-Competition-Report`
- https://github.com/SandOcean-ovo/Template-for-Electrical-Competition-Report
- 许可证：MIT

本项目继承的主要排版设置：

- `ctexart` 中文文档类；
- A4 页面，左右 2.5 cm、上 3 cm、下 2.5 cm；
- 宋体小四号正文；
- 22 pt 固定行距；
- 右下角页码；
- 摘要、方案、理论、电路与程序、测试等章节骨架；
- XeLaTeX 编译方式。

针对辽宁赛区 H 题所作的主要调整：

- 不使用通用模板中的目录页，避免在赛区格式尚未确认时占用正文；
- 按本题 20 分报告评分项重组章节；
- 增加“待确认、待实测、设计中”证据状态；
- 增加 `siunitx`、TikZ、三线表和分章节源码；
- 增加全国大学生电子设计竞赛标识；
- 插入本项目原理图、PCB图、电机驱动与电源电路图。

竞赛标识图像取自上海市政府英文网站的赛事介绍页面：
