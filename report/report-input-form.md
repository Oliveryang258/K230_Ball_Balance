# 填写完成后的处理

Codex 将按以下顺序处理：

1. 核对填写内容与原理图、PCB、代码是否一致。
2. 将信息标记为“已确认、已实测、待测、计划中”。
3. 先生成系统方案、电路设计和程序流程。
4. 再生成与实际代码一致的理论分析。
5. 维修后根据原始测试表生成曲线、统计量和测试结论。
6. 最后撰写摘要和结论，编译并逐页检查 PDF。
